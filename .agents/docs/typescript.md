# TypeScript conventions

- Use `import type` for type-only imports.
- Group external imports before internal imports.
- Use explicit return types on exported functions.
- Reserve `UPPER_SNAKE_CASE` for true constants.
- Follow the project's default Prettier configuration (`.prettierrc`) for formatting.

See [frontend patterns](frontend.md) and [API guidance](api-and-security.md) for context-specific conventions.
